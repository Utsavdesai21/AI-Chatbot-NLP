  # 🤖 AI Chatbot using NLP (Python)

This project is an AI-based chatbot developed using **Natural Language Processing (NLP)** techniques.  
The chatbot understands user queries and responds intelligently using **TF-IDF Vectorization** and **Cosine Similarity** instead of hardcoded if-else rules.

---

## 🚀 Features

- Understands user input using NLP
- Intelligent response matching
- Text preprocessing and similarity calculation
- Easy to extend with new questions and answers
- Beginner-friendly NLP project using Python
